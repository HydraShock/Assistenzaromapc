TRI-SITE ORDER ASSISTANT — COMMAND CENTER UI v3.0
==================================================

Questo pacchetto è un aggiornamento GRAFICO per la versione stabile v2.2.1.
Non modifica matching, cataloghi, regole apprese, stock o carrelli.

INSTALLAZIONE MANUALE (sicura)
-----------------------------
1. Apri la cartella dell'estensione v2.2.1.
2. Rinomina il file esistente:
      sidepanel.css  ->  sidepanel-base.css
3. Copia sidepanel-v3.css nella stessa cartella.
4. Rinomina:
      sidepanel-v3.css  ->  sidepanel.css
5. Apri chrome://extensions e premi Ricarica.
6. Chiudi e riapri il pannello laterale.

INSTALLAZIONE AUTOMATICA
------------------------
Windows: copia tutti i file nella cartella dell'estensione e avvia INSTALLA_V3_WINDOWS.bat
macOS: copia tutti i file nella cartella dell'estensione e avvia INSTALLA_V3_MAC.command

ROLLBACK
--------
Windows: RIPRISTINA_V2_WINDOWS.bat
macOS: RIPRISTINA_V2_MAC.command

COSA CAMBIA
-----------
- Header compatto e professionale.
- Navigazione Ordine / Verifica / Carrello ridotta e persistente.
- Area ordine meno alta e più leggibile.
- Risultati e metriche più dense.
- Carrello trasformato in action dock persistente.
- Regole e strumenti tecnici resi secondari.
- Dark mode e light mode progettati separatamente.
- Palette distinta per Smoking, La Tabaccheria e AER.
- Nessun CDN, font o script remoto.

NOTA
----
Il file sidepanel.css della v3 importa sidepanel-base.css. Non eliminare il file base finché utilizzi questo aggiornamento.
